# MCStuff

Сборки, ресурсы и инструменты для Minecraft.

Текущая версия содержит адаптивный интерфейс, главную MCStuff и единственный раздел Pack Builder. Функционал билдера сборок, Modrinth, поиск и скачивание пока не реализованы.

Интерфейс сайта полностью на английском языке.

Название MCStuff в боковой панели и мобильной шапке целиком Bold.

Подсветка кнопок меню анимирована, сами страницы переключаются мгновенно. Внизу бокового меню находятся пять акцентных цветов слева и значок Discord справа. Цвет меняется мгновенно с коротким тихим звуком. Главная открывается при входе и по клику на MCStuff; пункта Overview в меню нет.

Исходники и документация проекта находятся в [`MCStuff/`](MCStuff/README.md).

## Локальный запуск

Нужен Node.js 22 или новее. Установка зависимостей не требуется.

```powershell
cd MCStuff
npm run dev
```

Локальный адрес: `http://127.0.0.1:4173`. Проверка JavaScript: `npm run check`.

## Cloudflare Workers

- Root directory: корень репозитория (`/` или пустое значение).
- Build command: оставить пустым.
- Deploy command: `npx wrangler@4.156.1 deploy`. Стандартная команда `npx wrangler deploy` также найдёт корневой конфиг.
- Имя Worker: `mcstuff`.

Единственная конфигурация `wrangler.jsonc` находится в корне репозитория и указывает на `MCStuff/public`. Сборка не требуется. Локальная команда `npm run deploy` из `MCStuff` явно использует этот же конфиг. Подключение Workers выполняется в аккаунте владельца репозитория. Обновления отправляются только по его явной команде.
