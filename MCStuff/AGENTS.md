# Правила MCStuff

- Общаться с пользователем на русском, кратко и по делу. Сайт полностью на английском: все страницы, меню, заголовки вкладок, метаданные, сообщения и accessibility labels. Указывать `lang="en"`. Все новые функции сайта тоже писать на английском; переключатель языка не добавлять без запроса. Документацию и внутренние правила можно вести на русском.
- Перед изменениями читать этот файл, `README.md` и `CHANGELOG.md`; поддерживать их в актуальном состоянии. Не выводить документацию пользователю без необходимости.
- Название строго `MCStuff`. Это платформа Minecraft, где основное направление — быстрый подбор плагинов/модов и сборок через Modrinth; утилиты являются дополнительным направлением.
- Бренд MCStuff в sidebar и мобильной шапке целиком Bold (`font-weight: 700`). Не разделять MC и Stuff разным начертанием; подключать реальный вес 700 шрифта Golos Text.
- Текущий объём — Dark Modern, навигация / поиск, Colors & Formatting, три Checkers и рабочий Pack Builder. Пользователь явно разрешил Modrinth, SpigotMC / Spiget, подготовку CurseForge и сборку паков Plugins / Mods / Resource packs / Data packs. Аккаунты / база данных не добавляются. CurseForge key пока отсутствует; по ответу пользователя подключение подготовлено, активируется серверным CURSEFORGE_API_KEY.
- В навигации рабочий Pack Builder (`#builder`) и рабочий Colors & Formatting (`#colors`). Resources и Tools не возвращать; старые `#resources` и `#tools` открывают главную через общий fallback неизвестных hash. Главная по бренду сохранена и содержит ссылку на реальный рабочий инструмент.
- Категории sidebar — General и Checkers, в таком порядке. В General — Pack Builder и Colors & Formatting; в Checkers — Skin Stealer (`#skin`), Waypoint Color (`#waypoint`) и IGN Availability (`#ign`). Категорию указывать в `tool-catalog.js` и сохранять принадлежность ссылок к соответствующей `.nav-category` в HTML. Все три Checker работают; не подменять API-ответы заглушками.
- Skin Stealer получает публичный Java-скин по нику / UUID, показывает вращаемую 3D-модель через skinview3d 3.4.2 (Classic / Slim / legacy), Front / Back / Reset и исходную текстуру в details. Скачивать оригинальный PNG без преобразований. При отсутствии WebGL показывать честный 2D fallback. При уходе / редактировании освобождать SkinViewer, ResizeObserver и обработчики; скрытая вкладка приостанавливает рендер. Не подставлять вымышленный скин.
- Waypoint Color — стандартный цвет Locator Bar в Java по UUID.hashCode(): младшие RGB-байты, установка HSV-яркости 0.9, Java float / round. Не заменять это умножением RGB на 0.9. Реализация проверена по реальному ColorHelper клиента 1.21.7; 8 векторов в тестах. UUID считается локально; ник сначала разрешается через Mojang. Командный / team / plugin override может менять цвет; Bedrock не заявлять.
- IGN Availability проверяет Java-ник 3–16 символов: официальные GET, затем официальные POST profile lookup. Только официальный 404 / 204 или корректный пустой POST result означает Not registered; Taken — официальный профиль. При полном отказе официальных серверов разрешён явно помеченный PlayerDB fallback: Registered (cached) для исторического профиля, Unconfirmed / registered:null для отсутствия записи без live-подтверждения. Никогда не превращать это в «Available». 429 / невалидный ответ остаётся ошибкой. Не требовать токены Minecraft / Microsoft login.
- Checkers отправляют введённый идентификатор только по submit в same-origin API; состояние ввода / результатов хранится в памяти, не localStorage. Отменять клиентские запросы при редактировании / уходе, игнорировать устаревшие ответы. Успешное копирование и скачивание должны подтверждаться реальным содержимым, не только текстом кнопки.
- API в `worker/index.js`: `/api/player/:nameOrUuid`, `/api/uuid/:name`, `/api/ign/:name`, `/api/skin/:hash`. Поиск имени сначала через api.minecraftservices.com/minecraft/profile/lookup/name, затем официальный аналог на api.mojang.com. Старый users/profiles/minecraft не возвращать. При отказах допускается проверенный PlayerDB fallback; UUID / имя / texture URL валидировать, source / cachedAt / verification показывать явно. Отрицательный ответ PlayerDB не означает свободный ник; registered:null сохраняет отсутствие live-подтверждения. Резервный 400 признавать отсутствием записи только для точного code minecraft.invalid_username с success:false / error:false. 429 не обходить повторными запросами.
- Для fetch Checkers: timeout 5 s на источник, общий клиентский timeout 30 s, redirect manual и отказ на 3xx; error mode в workerd не поддерживается. Только фиксированные Mojang / sessionserver / textures / playerdb.co URL, лимит PNG, никаких произвольных proxy. PlayerDB получает идентифицирующий User-Agent со ссылкой на репозиторий. Ошибки API включают upstreamStatus / upstreamHost для диагностики, без сырых upstream-ответов / временных логов / секретов.
- Поиск фильтрует и ранжирует ссылки внутри категорий, не переносит их в корень nav. Пустые категории скрывать только при непустом запросе, после очистки возвращать обе группы, даже если набор / порядок найденных ссылок не изменился. Название категории тоже участвует в поиске инструментов; пустая Checkers сама по себе не является результатом поиска. Подсветка позиционируется относительно общей `.navigation`; обёртки групп оставлять без отдельного position-контекста либо пересчитывать координаты.
- Дизайн: Dark Modern, слева категории с иконками, справа широкая рабочая область. Фон, поверхности, основной текст и нейтральные разделители всегда одинаковые. Менять только дополнительный акцент. По последнему требованию палитра обычных насыщенных цветов: Green (по умолчанию, #22c55e), Blue (#4b91ff), Yellow (#facc15), Red (#ff5252), Purple (#a970ff). Amber и Rose заменены; при восстановлении старого выбора отображать их как Yellow и Red соответственно.
- Переключатели — только пять маленьких кружков слева снизу, gap 2px, контрол 22 × 28px. Выбранный цвет не обводить; допустимо небольшое увеличение. Для клавиатурного фокуса — отметка снизу. Discord остаётся у правого края.
- По последнему требованию свой акцент сайта удалён: не возвращать «+», `#custom-accent`, режим custom или CSS-переменную собственного акцента. Ранний скрипт очищает старый `mcstuff-custom-accent`, прежний режим custom заменяет на Green. В localStorage `mcstuff-theme` сохраняются только presets; восстановление до CSS, Green по умолчанию. HEX / color inputs внутри Colors & Formatting относятся к тексту Minecraft, а не к теме сайта.
- Colors & Formatting — локальный генератор и справочник Java / Adventure: все 16 цветов, пять декораций и reset; MiniMessage, Legacy & / §, HEX &# / §#, BungeeCord &x / §x, JSON. Поддерживать цвет / двухцветный градиент, Unicode без разрыва суррогатных пар, проверку HEX и отключение копирования при невалидном вводе. Legacy ограничен 16 цветами, цвета сбрасывают декорации — применять их повторно. MiniMessage экранирует пользовательские < и обратные слеши, закрывает теги в обратном порядке. Это генератор plain text, не полный парсер произвольного MiniMessage.
- Рабочие цвета / градиенты в preview и справочнике инструмента не являются темами или декоративными эффектами. Пользовательский текст выводить через textContent, не HTML; не отправлять его в сеть или localStorage. Состояние генератора сохраняется в памяти при переходах, после reload сбрасывается. Таймер obfuscated и уведомления о копировании останавливать при уходе со страницы. Показывать Copied только после успешной записи в clipboard; при отказе — выделение для ручного копирования.
- По последнему требованию поиск — настоящий input в sidebar; никаких dialog, popup, отдельной выдачи или блокировки страницы при вводе. Фильтровать существующие ссылки меню на месте, неподходящие скрывать через hidden, оставшиеся плавно перемещать / показывать. Открытый инструмент и его текст не менять до выбора результата. При очистке восстанавливать исходный порядок меню, при запросе сортировать по релевантности; подсветку текущей страницы скрывать, если её ссылка отфильтрована, и возвращать после очистки.
- Поиск использует только реальные инструменты из `public/tool-catalog.js`: названия, функции / синонимы, нормализация регистра / Unicode / пунктуации, короткие смысловые запросы, аббревиатуры CF / PB, русские aliases, исправление английского ввода в русской раскладке и ограниченный поиск по опечаткам / перестановкам букв. Все значимые слова должны совпасть; неизвестные запросы показывают No tools found. Ранжирование: точное название, слова / начало названия, aliases, приблизительные совпадения. Запрос ограничен 120 символами, работает локально без API, зависимостей и сохранения в localStorage.
- По последнему требованию горячей клавиши для поиска нет: не перехватывать Ctrl/Cmd+K и не показывать kbd / подсказку сочетания. На desktop ввод начинается кликом / обычным Tab в строку; мобильная кнопка Search tools открывает существующее боковое меню и фокусирует ту же строку. Стрелки переводят фокус по видимым ссылкам, Enter в строке открывает лучший результат, при пустой выдаче ничего не делает. Escape в строке сначала очищает запрос; если он уже пуст, возвращает фокус в main / закрывает мобильное меню. Clear search очищает и возвращает фокус в input. Мобильный цикл фокуса пропускает скрытые ссылки / кнопки; запрос сохраняется до очистки, reload сбрасывает его.
- По последнему требованию иконки брать готовыми, не рисовать вручную. Используется Lucide 1.70.0: package-plus, palette, scan-face, map-pin, user-round-check; menu / search / x / rotate-ccw из того же набора. Оригинальные пути в public/icons/lucide.svg, helper public/icons.js, полный ISC / Feather MIT license рядом. Бренд MCStuff и готовый Simple Icons Discord сохранены; не заменять лицензионные SVG самодельными похожими путями.
- Overview не показывать в меню. Главная открывается по умолчанию без hash и по клику на бренд MCStuff; её заголовок — MCStuff. Название вкладки (`<title>` / `document.title`) всегда строго `MCStuff` на главной и во всех разделах, без описаний и суффиксов. Заголовки разделов внутри страницы сохраняют свои названия. Старый `#overview` должен оставаться совместимым и открывать главную. Ссылки на конкретные разделы продолжать поддерживать.
- В нижней строке sidebar цвета выровнены влево, а значок Discord — вправо (`margin-left: auto`), на одной высоте с ними. Ссылка строго `https://discord.com/invite/xQqbSxAWJ9`, открывается в новой вкладке с `noopener noreferrer`, имеет английскую доступную подпись и видимый клавиатурный фокус. Не добавлять текст, цветной фон или баннер. Ссылка входит в цикл фокуса мобильного меню и не участвует во внутренней маршрутизации.
- По последнему требованию подсветка кнопок меню плавно скользит к выбранному разделу, а сами страницы переключаются мгновенно, без сдвига, затухания и перекрытия старого содержимого. Анимации подсветки и мобильного меню не должны автоматически отключаться при `prefers-reduced-motion: reduce`: это стало причиной отсутствия эффектов в опубликованной версии. Учитывать быстрые повторные клики и клавиатуру; в основной области всегда одна текущая страница.
- По последнему требованию смена акцента мгновенная: без волны, View Transition и плавного изменения цветов или размера выбранного кружка. При выборе другого цвета воспроизводить короткий тихий синусоидальный звук 70 ms через Web Audio API. При загрузке и повторном выборе текущего цвета этот звук не воспроизводится. Недоступность аудио не должна мешать смене цвета. Смена акцента не прерывает анимации навигации.
- При переходе между существующими разделами или на главную через меню, каталог / поиск воспроизводить другой короткий звук: triangle, 440 → 300 Hz, 50 ms, gain 0.025, как у смены цвета. При повторном выборе текущей страницы, загрузке, Discord и кликах с модификаторами звука нет. Оба звука используют один лениво созданный AudioContext; узлы отключаются после завершения, ошибки аудио не блокируют навигацию.
- Не показывать вымышленные API-результаты, версии игры, скачивания или активные элементы, которые ничего не делают. Нереализованные контролы, каталоги и счётчики не отображать даже в отключённом виде; в пустом разделе достаточно короткого фактического сообщения.
- Интерфейс должен быть чистым: без рекламных слоганов, обещаний будущих функций, повторяющихся карточек навигации, декоративных баннеров, глоу, градиентов и ярких цветных обводок. Выбранный цвет применять только как акцент бренда, активного пункта и выделения текста; тёмные поверхности не перекрашивать.
- Не добавлять фейковый профиль, аватар/букву пользователя, номер версии сайта, служебные статусы и текст о ходе разработки в интерфейс.
- Будущие версии и совместимость получать из актуальных источников; не хранить в интерфейсе вручную назначенную «последнюю версию».
- Пользователь разрешил оригинальные PNG шкалы и меток Waypoint для preview. Прочие игровые файлы без запроса не добавлять. public/textures/minecraft содержит locator_bar_background и четыре default_0…3 официального клиента Java 26.1.1 (SHA-1 проверен). PNG не изменять; provenance / hashes и авторство Mojang / Microsoft сохранять в NOTICE.txt, не объявлять игровые assets MIT. Nine-slice фона 12×5 с borders 5/5/1/1, масштаб 2×, 9×9 markers с sRGB tint без потери обводки / альфы; не возвращать нарисованные CSS-ромбы / шкалу.
- Frontend — buildless HTML/CSS/JavaScript; Worker без npm-зависимостей. Для требуемого 3D-превью vendored официальный skinview3d 3.4.2 bundle (~477 KB) с Three.js r156 и skinview-utils 0.7.1, лицензии в public/vendor/skinview3d. Загружается лениво, не через CDN. Не редактировать bundle вручную. `scripts/dev.mjs` использует тот же handleApi, что Cloudflare; local Worker — Wrangler dev. Фреймворк ради layout не добавлять.
- Целевой workflow — GitHub → Cloudflare Workers в аккаунте пользователя. Не создавать отдельный Sites-hosting, домен или вложенный Git-репозиторий вместо выбранного workflow.
- Пользователь сам подключает GitHub и Cloudflare. Локальные правки и проверки выполнять по запросу; commit, push, upload и deploy делать только по отдельной явной команде пользователя на публикацию. Просьба изменить сайт сама по себе не разрешает отправку обновлений. Если push запускает автодеплой, он также требует такой команды.
- Репозиторий: `https://github.com/TheMCP123/mcstuff`, remote `origin`, основная ветка `main`. Git checkout находится в родительской папке, исходники сайта — в `MCStuff`. Workers Builds Root directory — корень репозитория (`/` или пусто). Сохранять существующую историю, не использовать force-push.
- Выбранная лицензия — MIT. Файл `LICENSE` находится в корне репозитория, Copyright (c) 2026 MCP; сохранять его текст и авторство. В `package.json` использовать `MIT`, не добавлять отдельные ограничения zlib или правила бренда без нового запроса.
- Единственный `wrangler.jsonc` хранить в корне репозитория: имя `mcstuff`, Static Assets из `./MCStuff/public`; имя Worker в Cloudflare должно совпадать. Не возвращать конфиг только в подпапку: первая сборка запускала `npx wrangler deploy` из корня и падала, не находя assets. `npm run deploy` из `MCStuff` должен явно передавать `--config ../wrangler.jsonc`. Закреплённая версия CLI — 4.156.1. Секреты и `.wrangler` не коммитить.
- Корневой Wrangler также содержит main `./MCStuff/worker/index.js`, assets binding ASSETS и run_worker_first для `/api` / `/api/*`, иначе SPA может перехватить API-запрос. Не возвращать чисто статический deploy: он сломает сетевые Checkers. Для backend-изменений проверять и Node preview, и настоящий локальный workerd.
- Текущий публичный адрес: https://mcstuff.max-gusak-work.workers.dev/; пользователь предупредил, что скоро сменит его. API / иконки / preview assets всегда same-origin relative, домен в клиентском коде не фиксировать. После сетевых исправлений проверять реальные /api/uuid, /api/player, /api/ign и PNG на опубликованном адресе: локальные 200 и успешный CI не доказывают доступность Mojang из edge-региона Workers.
- Сохранять адаптивность от 320 px, семантическую разметку, видимый фокус и управление меню клавиатурой. Не возвращать CSS или JS, полностью отключающие движение по media preference, без нового требования пользователя.
- Системные select / color picker заменены общими кастомными контролами: public/form-controls.js + form-controls.css, чистые HSV / поиск / позиционирование в control-data.js. Нативные поля скрыты и служат источником состояния / input / change; не возвращать видимые OS popup. После программной смены value / disabled вызывать refreshFormControls(host), динамические options / поля отслеживает observer. Обязательно освобождать enhancement вместе с инструментом, закрывать popup при уходе / скрытии / отключении anchor. Сохранять ARIA, Tab / Escape / Enter / стрелки / Home / End, пропуск disabled и поиск в длинных списках. Цветовой picker — HSV plane / keyboard sliders / HEX; невалидный HEX не применяется, Done отключён; popup с ошибкой остаётся в viewport. Checkbox / progress / scrollbars / disclosure / tooltip оформлять в общем стиле без системных синих элементов.
- Pack Builder: контролы от 44px, Search 48px, крупные Add / Download, единая сетка фильтров и карточек. Your pack — собственная кнопка aria-expanded и body, на мобильном изначально свёрнут; ошибки раскрывают его. На desktop список файлов прокручивается внутри панели, действия скачивания остаются доступны. Clear project search — собственная кнопка.
