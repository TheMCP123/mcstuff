# Правила MCStuff

- Общаться с пользователем на русском, кратко и по делу. Сайт полностью на английском: все страницы, меню, заголовки вкладок, метаданные, сообщения и accessibility labels. Указывать `lang="en"`. Все новые функции сайта тоже писать на английском; переключатель языка не добавлять без запроса. Документацию и внутренние правила можно вести на русском.
- Перед изменениями читать этот файл, `README.md` и `CHANGELOG.md`; поддерживать их в актуальном состоянии. Не выводить документацию пользователю без необходимости.
- Название строго `MCStuff`. Это платформа Minecraft, где основное направление — быстрый подбор плагинов/модов и сборок через Modrinth; утилиты являются дополнительным направлением.
- Бренд MCStuff в sidebar и мобильной шапке целиком Bold (`font-weight: 700`). Не разделять MC и Stuff разным начертанием; подключать реальный вес 700 шрифта Golos Text.
- Развивать постепенно. Текущий объём — Dark Modern layout, навигация со звуком, поиск инструментов, рабочий Colors & Formatting и каркас Pack Builder. Не подключать Modrinth API, скачивание, аккаунты или базу данных без следующего запроса.
- В навигации Pack Builder (`#builder`, пока без функций) и рабочий Colors & Formatting (`#colors`). Resources и Tools не возвращать; старые `#resources` и `#tools` открывают главную через общий fallback неизвестных hash. Главная по бренду сохранена и содержит ссылку на реальный рабочий инструмент.
- Дизайн: Dark Modern, слева категории с иконками, справа широкая рабочая область. Фон, поверхности, основной текст и нейтральные разделители всегда одинаковые. Менять только дополнительный акцент. По последнему требованию палитра обычных насыщенных цветов: Green (по умолчанию, #22c55e), Blue (#4b91ff), Yellow (#facc15), Red (#ff5252), Purple (#a970ff). Amber и Rose заменены; при восстановлении старого выбора отображать их как Yellow и Red соответственно.
- Переключатели — только пять маленьких кружков слева снизу, gap 2px, контрол 22 × 28px. Выбранный цвет не обводить; допустимо небольшое увеличение. Для клавиатурного фокуса — отметка снизу. Discord остаётся у правого края.
- По последнему требованию свой акцент сайта удалён: не возвращать «+», `#custom-accent`, режим custom или CSS-переменную собственного акцента. Ранний скрипт очищает старый `mcstuff-custom-accent`, прежний режим custom заменяет на Green. В localStorage `mcstuff-theme` сохраняются только presets; восстановление до CSS, Green по умолчанию. HEX / color inputs внутри Colors & Formatting относятся к тексту Minecraft, а не к теме сайта.
- Colors & Formatting — локальный генератор и справочник Java / Adventure: все 16 цветов, пять декораций и reset; MiniMessage, Legacy & / §, HEX &# / §#, BungeeCord &x / §x, JSON. Поддерживать цвет / двухцветный градиент, Unicode без разрыва суррогатных пар, проверку HEX и отключение копирования при невалидном вводе. Legacy ограничен 16 цветами, цвета сбрасывают декорации — применять их повторно. MiniMessage экранирует пользовательские < и обратные слеши, закрывает теги в обратном порядке. Это генератор plain text, не полный парсер произвольного MiniMessage.
- Рабочие цвета / градиенты в preview и справочнике инструмента не являются темами или декоративными эффектами. Пользовательский текст выводить через textContent, не HTML; не отправлять его в сеть или localStorage. Состояние генератора сохраняется в памяти при переходах, после reload сбрасывается. Таймер obfuscated и уведомления о копировании останавливать при уходе со страницы. Показывать Copied только после успешной записи в clipboard; при отказе — выделение для ручного копирования.
- Поиск использует реестр `public/tool-catalog.js`, реальные названия и aliases. Открывается кнопками sidebar / мобильной шапки и Ctrl/Cmd+K; фильтрация, стрелки, Enter, Escape, клик по результату и закрытие фоном должны работать. Анимировать только поиск и его результаты; страницы по-прежнему переключаются сразу. При Escape в поисковом input предотвращать стандартную очистку, закрывать dialog с первого нажатия. Сохранять фокус и работу мобильного меню.
- Overview не показывать в меню. Главная открывается по умолчанию без hash и по клику на бренд MCStuff; её заголовок — MCStuff. Название вкладки (`<title>` / `document.title`) всегда строго `MCStuff` на главной и во всех разделах, без описаний и суффиксов. Заголовки разделов внутри страницы сохраняют свои названия. Старый `#overview` должен оставаться совместимым и открывать главную. Ссылки на конкретные разделы продолжать поддерживать.
- В нижней строке sidebar цвета выровнены влево, а значок Discord — вправо (`margin-left: auto`), на одной высоте с ними. Ссылка строго `https://discord.com/invite/xQqbSxAWJ9`, открывается в новой вкладке с `noopener noreferrer`, имеет английскую доступную подпись и видимый клавиатурный фокус. Не добавлять текст, цветной фон или баннер. Ссылка входит в цикл фокуса мобильного меню и не участвует во внутренней маршрутизации.
- По последнему требованию подсветка кнопок меню плавно скользит к выбранному разделу, а сами страницы переключаются мгновенно, без сдвига, затухания и перекрытия старого содержимого. Анимации подсветки и мобильного меню не должны автоматически отключаться при `prefers-reduced-motion: reduce`: это стало причиной отсутствия эффектов в опубликованной версии. Учитывать быстрые повторные клики и клавиатуру; в основной области всегда одна текущая страница.
- По последнему требованию смена акцента мгновенная: без волны, View Transition и плавного изменения цветов или размера выбранного кружка. При выборе другого цвета воспроизводить короткий тихий синусоидальный звук 70 ms через Web Audio API. При загрузке и повторном выборе текущего цвета этот звук не воспроизводится. Недоступность аудио не должна мешать смене цвета. Смена акцента не прерывает анимации навигации.
- При переходе между существующими разделами или на главную через меню, каталог / поиск воспроизводить другой короткий звук: triangle, 440 → 300 Hz, 50 ms, gain 0.025, как у смены цвета. При повторном выборе текущей страницы, загрузке, Discord и кликах с модификаторами звука нет. Оба звука используют один лениво созданный AudioContext; узлы отключаются после завершения, ошибки аудио не блокируют навигацию.
- Не показывать вымышленные API-результаты, версии игры, скачивания или активные элементы, которые ничего не делают. Нереализованные контролы, каталоги и счётчики не отображать даже в отключённом виде; в пустом разделе достаточно короткого фактического сообщения.
- Интерфейс должен быть чистым: без рекламных слоганов, обещаний будущих функций, повторяющихся карточек навигации, декоративных баннеров, глоу, градиентов и ярких цветных обводок. Выбранный цвет применять только как акцент бренда, активного пункта и выделения текста; тёмные поверхности не перекрашивать.
- Не добавлять фейковый профиль, аватар/букву пользователя, номер версии сайта, служебные статусы и текст о ходе разработки в интерфейс.
- Будущие версии и совместимость получать из актуальных источников; не хранить в интерфейсе вручную назначенную «последнюю версию».
- Состав ресурсов Minecraft пока не уточнён. Не трактовать это автоматически как разрешение распространять проприетарные игровые файлы.
- Текущий код — buildless HTML/CSS/JavaScript. Не добавлять фреймворки или зависимости только ради layout. При необходимости изменения архитектуры документировать причину.
- Целевой workflow — GitHub → Cloudflare Workers в аккаунте пользователя. Не создавать отдельный Sites-hosting, домен или вложенный Git-репозиторий вместо выбранного workflow.
- Пользователь сам подключает GitHub и Cloudflare. Локальные правки и проверки выполнять по запросу; commit, push, upload и deploy делать только по отдельной явной команде пользователя на публикацию. Просьба изменить сайт сама по себе не разрешает отправку обновлений. Если push запускает автодеплой, он также требует такой команды.
- Репозиторий: `https://github.com/TheMCP123/mcstuff`, remote `origin`, основная ветка `main`. Git checkout находится в родительской папке, исходники сайта — в `MCStuff`. Workers Builds Root directory — корень репозитория (`/` или пусто). Сохранять существующую историю, не использовать force-push.
- Выбранная лицензия — MIT. Файл `LICENSE` находится в корне репозитория, Copyright (c) 2026 MCP; сохранять его текст и авторство. В `package.json` использовать `MIT`, не добавлять отдельные ограничения zlib или правила бренда без нового запроса.
- Единственный `wrangler.jsonc` хранить в корне репозитория: имя `mcstuff`, Static Assets из `./MCStuff/public`; имя Worker в Cloudflare должно совпадать. Не возвращать конфиг только в подпапку: первая сборка запускала `npx wrangler deploy` из корня и падала, не находя assets. `npm run deploy` из `MCStuff` должен явно передавать `--config ../wrangler.jsonc`. Закреплённая версия CLI — 4.156.1. Секреты и `.wrangler` не коммитить.
- Сохранять адаптивность от 320 px, семантическую разметку, видимый фокус и управление меню клавиатурой. Не возвращать CSS или JS, полностью отключающие движение по media preference, без нового требования пользователя.
- Проверять изменённый JavaScript через `npm run check`; при изменениях layout открывать локальный preview и проверять desktop/mobile, если browser tools доступны. Не выдавать локальную проверку за подтверждённый Cloudflare deployment.
- Для форматтеров и поиска запускать `npm test` (Node test runner без зависимостей). Проверять цвета / декорации, escaping, RGB-префиксы, JSON, Unicode и gradients, а также поисковые aliases. Копирование проверять фактическим содержимым clipboard, не только уведомлением.
- Результат Cloudflare проверять по актуальному списку GitHub `/repos/TheMCP123/mcstuff/commits/<sha>/check-runs`; не опрашивать бесконечно один сохранённый check-run ID: завершённая проверка может иметь другой ID.
