# MCStuff

Рабочее пространство для Minecraft. Основное направление — подбор плагинов и модов через Modrinth под выбранные версию игры и платформу с последующим скачиванием. Ресурсы Minecraft и другие инструменты будут добавляться отдельно.

## Текущее состояние

Адаптивный каркас: тёмная палитра, боковая навигация и широкая рабочая область. Весь интерфейс на английском: главная MCStuff и разделы Pack Builder, Resources, Tools. Это также относится к заголовкам вкладок, метаданным, accessibility labels и сообщению при отключённом JavaScript; HTML language — `en`. Будущие функции сайта тоже должны быть на английском. Пока разделы пустые; отображаются только заголовок и краткое фактическое сообщение. Общение с пользователем и документация остаются на русском.

Overview убран из меню. Главная открывается по умолчанию и по клику на бренд вверху слева (на мобильном — также в шапке). Hash-ссылки разделов сохранены; прежний `#overview` открывает главную. Подсветка меню скользит к выбранному пункту, содержимое смещается и затухает; быстрые переходы отменяют предыдущую анимацию.

Слева снизу находятся пять компактно расположенных кружков: Green, Blue, Purple, Amber, Rose. Группа выровнена по левому краю, gap — 2px; у выбранного цвета нет обводки, он слегка увеличен. Меняется только акцент: знак бренда, активный пункт, выделение текста и фокус. Фон, поверхности, основной текст, нейтральные линии и browser theme-color сохраняются одинаковыми в стиле Dark Modern. Выбор хранится только в localStorage `mcstuff-theme` и восстанавливается ранним скриптом из HTML до CSS. По последнему требованию акцент меняется мгновенно, без волны и переходов цветов или размера кружка. Кнопки доступны с клавиатуры, имеют английские подписи и `aria-pressed`; клавиатурный фокус отмечен коротким штрихом снизу. Мобильное меню поддерживает Escape и удержание фокуса, включая переключатели тем. Анимации навигации и мобильного меню сохранены независимо от `prefers-reduced-motion`.

Выбор другого цвета сопровождается тихим синусоидальным щелчком длительностью 70 ms (760 → 580 Hz, пиковый gain 0.025, мягкая огибающая) через Web Audio API, без звуковых файлов и зависимостей. Один AudioContext создаётся после действия пользователя, при необходимости возобновляется и используется повторно; звуковые узлы отключаются после завершения. При загрузке, повторном выборе текущего цвета и навигации звука нет. Если аудио недоступно, смена акцента продолжает работать. Быстрые клики не блокируются и не прерывают навигацию.

Поиск, получение версий, подбор зависимостей и скачивание ещё не реализованы. Их макеты, отключённые поля и фиктивные счётчики удалены. API Modrinth пока не вызывается. В интерфейсе нет рекламных обещаний, профиля, номера версии, служебных статусов, декоративных баннеров, градиентов, глоу и цветных обводок.

## Технологии и структура

На этапе layout: HTML, CSS и JavaScript ES modules без сборщика и npm-зависимостей. Для будущего API можно добавить Worker в тот же проект. React/TypeScript/Vite обсуждались как предложение, но пока не установлены: текущему каркасу они не нужны.

- `public/index.html` — постоянный каркас: меню, мобильная шапка и основная область.
- `public/styles.css` — оформление, адаптивность от 320 px и CSS-переходы.
- `public/app.js` — иконки, маршрутизация главной и разделов, анимации, темы и мобильное меню.
- `public/favicon.svg` — собственный знак MCStuff.
- `scripts/dev.mjs` — локальный HTTP-сервер на Node.js, только loopback.
- `../wrangler.jsonc` — единственный конфиг Cloudflare Workers Static Assets в корне репозитория; каталог `MCStuff/public`, SPA fallback, имя Worker `mcstuff`, compatibility date `2026-11-01`.
- `../LICENSE` — MIT, Copyright (c) 2026 MCP; сохранена лицензия, созданная владельцем GitHub-репозитория.

Шрифт Golos Text загружается с Google Fonts; при отсутствии сети используется системный шрифт. Других внешних ресурсов и запросов в текущем интерфейсе нет.

## Локальная работа

Нужен Node.js 22 или новее. Проверено на Node.js 24.16.0, npm 11.13.0.

После добавления анимаций проверены главная без hash, совместимость `#overview`, переход по бренду, три раздела, быстрые переходы и ровно одна текущая страница после завершения анимации. Все пять акцентов сохраняют цвета фона `rgb(16, 17, 19)` и sidebar `rgb(21, 22, 25)`. Проверены отсутствие кольца, gap 2px, выравнивание влево и сохранение выбора после reload. На 320 px проверены меню, темы с клавиатуры, цикл фокуса и Escape; горизонтального переполнения нет. Ошибок и предупреждений в консоли не зарегистрировано.

Первоначально основной браузерный preview сообщал `prefers-reduced-motion: reduce`, из-за чего код полностью отключал эффекты. После сообщения пользователя об отсутствии анимаций из JS и CSS удалено это автоматическое отключение. Проверять эффекты нужно в основном preview на исходных файлах, без временной копии с изменёнными media queries. Локальные проверки и Cloudflare deployment подтверждаются отдельно.

Скольжение меню проверено в основном preview при той же media preference: длительность подсветки 0.36 s, подтверждены промежуточное положение 29.4 px при цели 98 px и opacity входящей страницы около 0.26. Волна акцента впоследствии удалена по новому требованию пользователя.

После удаления волны проверены мгновенное применение акцента (CSS-переходы 0 s), клавиатурный выбор, повторное нажатие и сохранение выбора после reload. Навигация продолжает анимироваться: промежуточное положение подсветки 67.5 px при цели 98 px, opacity страницы около 0.44. Фон и sidebar сохраняют прежние цвета; консоль без ошибок и предупреждений, `npm run check` пройден.

```powershell
npm run dev
npm run check
```

Открыть `http://127.0.0.1:4173`. Для другого порта задать переменную окружения `PORT`. Установка зависимостей и сборка для локального запуска не нужны.

## GitHub → Cloudflare Workers

Репозиторий: [TheMCP123/mcstuff](https://github.com/TheMCP123/mcstuff), remote `origin`, ветка `main`. Текущий Git checkout находится в родительской папке, исходники сайта — в `MCStuff`. Начальный коммит владельца с MIT сохранён. Отдельный вложенный Git-репозиторий не создавался. Первая версия сайта загружена по явной команде пользователя коммитом `49e54f7`. Cloudflare подключён пользователем; первый deploy завершился ошибкой поиска статических файлов: команда выполнялась из корня репозитория, а конфиг находился в `MCStuff`. Конфиг перенесён в корень, каталог assets — `MCStuff/public`.

Проверка исправления: Wrangler 4.156.1 успешно выполнил `deploy --dry-run` из корня, а `npm run deploy -- --dry-run` — из `MCStuff`. В обоих случаях обнаружены все 4 файла `MCStuff/public`. Отдельно подтверждена успешная Cloudflare проверка `Workers Builds: mcstuff` для коммита `0c85f29`. При следующих публикациях проверяется актуальный список check-runs соответствующего коммита, поскольку ID проверки может меняться.

Пользователь самостоятельно подключает Cloudflare. Ассистент отправляет обновления только по отдельной явной команде пользователя на commit/push/upload/deploy. Обычный запрос на изменение сайта разрешает локальные правки и проверки, но не публикацию. При настроенном Workers Builds push может запустить автодеплой.

При подключении репозитория в Cloudflare:

- Root directory: корень репозитория (`/` или пустое значение).
- Build command: не требуется.
- Deploy command: `npx wrangler@4.156.1 deploy`. Уже установленная команда `npx wrangler deploy` также поддерживается.
- Worker name: `mcstuff` (должно совпадать с `wrangler.jsonc`).
- Раздаваемый каталог: `MCStuff/public`, задан в корневом `wrangler.jsonc`.

В локальной команде и рекомендуемой команде Workers Builds закреплён Wrangler 4.156.1, совпадающий с версией из первого build log пользователя. Локальная команда публикации после авторизации Cloudflare: `npm run deploy` из `MCStuff`; она передаёт `--config ../wrangler.jsonc`. Для проверки подготовки без публикации из корня репозитория: `npx wrangler@4.156.1 deploy --dry-run`.

Адрес по умолчанию: `mcstuff.<поддомен-аккаунта>.workers.dev`. Поддомен аккаунта выбирается в Cloudflare; собственный домен для старта не требуется. Конкретный адрес появится только после подключения аккаунта и деплоя.

Документация Cloudflare: [Workers Builds](https://developers.cloudflare.com/workers/ci-cd/builds/), [Static Assets](https://developers.cloudflare.com/workers/static-assets/), [workers.dev](https://developers.cloudflare.com/workers/configuration/routing/workers-dev/).
