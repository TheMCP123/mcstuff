# История изменений

## Английский интерфейс — 2026-11-01

- Весь сайт переведён на английский: Overview, Pack Builder, Resources и Tools; заголовки страниц и вкладок, пустые состояния, статические и динамические подписи меню, accessibility labels, метаданные и сообщение без JavaScript.
- HTML language изменён на `en`, описание package.json переведено на английский.
- Английский закреплён как постоянный язык интерфейса для следующих функций; общение с пользователем остаётся на русском.
- Проверены все четыре страницы, `lang="en"`, английские метаданные, Open/Close menu и Escape на ширине 320 px; горизонтального переполнения и ошибок в консоли нет. Проверка синтаксиса пройдена, в `public` кириллицы не осталось.

## Исправление первого deployment — 2026-11-01

- Исправлена ошибка `Could not detect a directory containing static files`: единственный `wrangler.jsonc` перенесён из `MCStuff` в корень репозитория, assets.directory указывает на `./MCStuff/public`.
- Поддерживается запуск Cloudflare `npx wrangler deploy` из корня. Команда `npm run deploy` из подпапки явно передаёт путь к тому же конфигу.
- В рекомендуемой команде публикации закреплён Wrangler 4.156.1; в корне добавлены исключения Git для `.wrangler`, npm-кэша внутри неё, зависимостей и локальных секретов.
- Обновлены настройки Workers Builds: Root directory — корень репозитория; сборка не нужна. Интерфейс сайта не изменялся.
- Проверены оба dry-run на Wrangler 4.156.1: запуск из корня и через npm из `MCStuff`; каждый обнаружил все 4 статических файла. Проверка синтаксиса JavaScript также пройдена.
- Cloudflare проверка `Workers Builds: mcstuff` для фикс-коммита `0c85f29` завершилась успешно.
