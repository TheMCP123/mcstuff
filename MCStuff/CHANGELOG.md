# История изменений

## Звук выбора акцента — 2026-11-01

- По новому требованию удалены волна View Transition и CSS-переходы цветов и размера кружка: выбранный акцент применяется мгновенно.
- При выборе другого цвета добавлен тихий звук длительностью 70 ms через Web Audio API, без файлов и зависимостей. Звук отсутствует при загрузке и повторном выборе текущего цвета; ошибки аудио не блокируют интерфейс.
- Удалены устаревшие обработчики волны и принудительная остановка навигации при смене цвета. Скольжение меню, переходы страниц, мобильное меню, Dark Modern и сохранение акцента оставлены.
- Пройдены `npm run check` и `git diff --check`. В основном preview подтверждены CSS-длительности смены акцента 0 s, сохранение выбора после reload, клавиатурное переключение и сохранённое скольжение меню 0.36 s; фон и sidebar не изменяются, консоль без ошибок и предупреждений.
- Обновлены документация и внутренние правила. Публикация разрешена явной командой пользователя.

## Исправление отключённых анимаций — 2026-11-01

- По сообщению пользователя об отсутствии анимаций удалены JS-проверки и CSS media rule, полностью отключавшие эффекты при `prefers-reduced-motion: reduce`.
- Скольжение меню, переходы страниц, волна акцента и анимации мобильного меню теперь включены независимо от этой media preference, как требует пользователь.
- Сохранены Dark Modern фон, компактные кружки без кольца, английский интерфейс и клавиатурное управление.
- На исходных файлах в основном preview с media preference reduce подтверждены ненулевые CSS-переходы, промежуточные кадры меню и страницы и расширяющаяся волна акцента; консоль без ошибок, JavaScript syntax check пройден.

## Анимации и акценты — 2026-11-01

- Удалён пункт Overview: главная открывается по умолчанию и по клику на MCStuff. Старый `#overview` открывает главную, ссылки разделов сохранены.
- Добавлены скользящая подсветка меню и переход содержимого со сдвигом и затуханием, включая отмену предыдущих анимаций при быстрых переходах.
- Слева снизу добавлены пять цветовых кружков: Green, Blue, Purple, Amber, Rose. По уточнённому требованию они меняют только акцент, фон и поверхности Dark Modern сохраняются. Группа выровнена влево, gap уменьшен до 2px, обводка выбранного цвета удалена.
- Добавлены круговая волна от переключателя через View Transition API (680 ms), fallback смены цветов, сохранение темы в localStorage и раннее восстановление при загрузке.
- Сохранены английский интерфейс, клавиатурное управление и `prefers-reduced-motion`. Новые переключатели включены в цикл фокуса мобильного меню.
- Проверены обычные анимации в изолированном preview и reduced-motion в основном: скольжение, волна только акцента, быстрые повторные клики, главная и переходы, сохранение выбора при reload, клавиатура и меню на ширине 320 px. Фон и sidebar остаются неизменными при всех пяти акцентах; консоль без ошибок.
- Обновление публикуется по явной команде пользователя.
