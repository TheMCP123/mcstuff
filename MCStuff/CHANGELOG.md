## Base Finding → Bedrock Leak v1 — 2026-11-11

- Добавлена третья категория Base Finding и рабочий Bedrock Leak (`#bedrock`), оригинальная Lucide scan-search и поисковые aliases категории / bedrock / seed / координат на английском и русском. Все прежние инструменты сохранены.
- Редактор горизонтального рисунка 10 × 10: Bedrock / Other / Unknown, кисть с протягиванием, Fill other / Clear, клавиатурная навигация и ARIA. Default Y=-61 — третий блок над сплошным Y=-64; доступны Y=-63…-60. Минимум 8 известных клеток, Unknown игнорируется, Other — точное отрицательное условие.
- Собственные JS / WAT / WASM: seed signed 64-bit без Number-потерь, named positional RNG / Xoroshiro128++, Java overflow / shifts, строгие пороги слоёв, четыре поворота без симметричных дублей. Поддержка сверена для неизменённого vanilla Overworld Java 1.21.11 / 26.3; Bedrock Edition / Nether / custom generation / retrogen не заявлены. Игровой код и GPL-реализации не включались.
- Реальный поиск в module Worker по квадрату Center X/Z ± Radius 0…8192, default 512; это не полный перебор мира. Прогресс / время / Stop, лимит 100 совпадений с честным сообщением о неполном поиске. Результаты содержат NW-угол всей области, выбранный Y и поворот; Copy записывает только X Y Z, при блокировке буфера выделяет их для ручного копирования. Seed / сетка / результаты только в памяти; редактирование сбрасывает результаты, уход завершает Worker, устаревшие сообщения игнорируются.
- В public добавлен готовый 517-byte WASM, dev-сервер отдаёт application/wasm; preview / deploy остаются без обязательной сборки. Добавлены build:bedrock, закреплённые devDependencies WABT 1.0.39 / Happy DOM 21.0.4 и package-lock; npm ci нужен для тестов / пересборки. Документация, корневой README и внутренние правила обновлены.
- Пройдены syntax check и все 98 тестов: 504 отсчёта / 14 рисунков реального vanilla RNG из SHA1-проверенных официальных серверов, границы seed / координат, повороты / Unknown / Other / лимит, соответствие WASM исходнику, реальный Worker, DOM-редактор / найденные координаты / clipboard / Stop / уход.
