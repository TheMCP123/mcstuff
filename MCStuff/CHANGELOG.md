# История изменений

## Первая загрузка в GitHub — 2026-11-01

- По явной команде пользователя подключён репозиторий `TheMCP123/mcstuff`, ветка `main`; сохранён начальный коммит владельца с MIT и автором MCP.
- Подготовлена первая загрузка очищенного layout в папке `MCStuff`. Root directory для Workers Builds — `MCStuff`.
- Обновлён корневой README с локальным запуском, настройками Workers и ссылкой на MIT; в `package.json` добавлено `license: MIT`.
- Подключение и deployment Cloudflare не проверены; GitHub push и состояние хостинга учитываются отдельно.

## Очистка layout — 2026-11-01

- Удалены рекламный баннер, декоративные кубы, повторяющиеся карточки категорий, обещания будущих функций и текст о ходе разработки.
- Удалены фейковый профиль с буквой M, номер версии сайта, служебные статусы и лишний подвал.
- Удалён макет неработающего каталога и скачивания: в разделах остались заголовок и краткое сообщение о пустом состоянии.
- Заменены цветные обводки, градиенты и декоративные тени на нейтральные поверхности и линии; сохранены боковая навигация и мобильное меню.
- Закреплено правило: пользователь подключает GitHub/Cloudflare, ассистент выполняет commit/push/upload/deploy только по отдельной явной команде. Эти правки не отправлялись.
- Проверены синтаксис JavaScript, все разделы, меню и Escape; при ширине 320 px нет горизонтального переполнения. Консоль браузера без ошибок и предупреждений.

## 0.1.0 — 2026-11-01

- Создан первый layout MCStuff: тёмное оформление, зелёный акцент, собственный SVG-знак и иконки, постоянное левое меню и широкая рабочая область.
- Добавлены обзор, макет билдера сборок и страницы-заготовки ресурсов и инструментов.
- Добавлены навигация по URL hash, выделение текущего раздела, адаптивное меню, клавиатурное управление и поддержка уменьшения движения.
- Будущий функционал отмечен как недоступный. Поиск и скачивание отключены, интеграция Modrinth не добавлялась.
- Подготовлены локальный сервер без npm-зависимостей и конфигурация Cloudflare Workers Static Assets для будущего GitHub deployment.
- Сохранены назначение проекта, текущая структура, команды и внутренние правила. GitHub и Cloudflare пока не подключены.
- Проверены синтаксис JavaScript, локальный HTTP 200, навигация по разделам, мобильное меню и ширины 320/390 px. Переход к содержимому сохраняет открытый раздел.
